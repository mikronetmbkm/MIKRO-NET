Pasang IP & Uji Ping

Setiap port router yang tersambung ke PC diberi IP. IP itulah yang menjadi gateway PC. Setelah router dan PC diatur, uji dengan ping.

Bagian A: IP pada interface router

Di Winbox: IP → Addresses, klik +. Tulis alamat lengkap dengan prefix, misalnya 192.168.11.1/24. Kolom Network terisi otomatis.

Tugas:
  • Pasang IP untuk ether2 dan ether3 sesuai topologi, lalu tekan Periksa IP router.
