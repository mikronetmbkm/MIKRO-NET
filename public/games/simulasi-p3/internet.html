Internet & Firewall

Di simulasi ini ether1 tersambung ke internet, jadi kamu bisa melihat hasil yang di lab mungkin belum bisa dicoba. Konfigurasi router dan PC dari Misi 2 tetap dipakai.

Bagian A: DHCP Client di ether1

ether1 tersambung ke jaringan ISP yang sudah punya server DHCP. Router cukup meminta IP secara otomatis: IP → DHCP Client, klik +.

Tugas:
  • Buat DHCP Client sampai statusnya bound dan router punya rute ke internet.
DHCP Client▢ ✕
New DHCP Client

    Bagian B: DNS

    DNS menerjemahkan nama seperti google.com menjadi alamat IP. Buka IP → DNS.

    Tugas:
    • Isi server DNS 8.8.8.8 dan izinkan PC memakai router sebagai DNS.
    DNS Settings✕

      Bagian C: NAT masquerade

      IP PC (192.168.11.2) adalah IP privat yang tidak dikenal di internet. NAT masquerade mengganti alamat pengirim dengan IP router di ether1, sehingga balasan dari internet bisa kembali ke router, lalu diteruskan ke PC.

      Tugas:
      • Buat aturan NAT di IP → Firewall → NAT agar PC bisa ke internet.
      Firewall▢ ✕
      Filter RulesNATMangle
      New NAT Rule

        Bagian D: Uji koneksi internet

        Coba dari router (Terminal Winbox) dan dari PC1. Bandingkan hasil ping ke IP (8.8.8.8) dengan ping ke nama (google.com).

        Pilih salah satu uji di atas.

          Bagian E: Firewall filter

          Filter Rules menentukan lalu lintas mana yang diizinkan atau diblokir. Chain forward berlaku untuk paket yang melewati router (misalnya PC1 ke PC2); chain input untuk paket yang menuju router itu sendiri.

          Tugas:
          • Blokir ping dari jaringan PC1 ke jaringan PC2, buktikan ping gagal, lalu nonaktifkan aturannya dan buktikan ping berhasil lagi.
