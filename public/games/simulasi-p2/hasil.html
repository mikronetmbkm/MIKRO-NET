Rincian skor

    Yang perlu kamu ingat saat praktik

    • Port ke PC = access + VLAN-nya. Port ke router = trunk. Cek dengan show vlan brief.
    • Angka encapsulation dot1Q harus sama dengan VLAN ID. IP subinterface = gateway PC.
    • Jangan lupa no shutdown di interface g0/0; kalau lupa, semua subinterface ikut mati.
    • DHCP: Discover → Offer → Request → Acknowledge. Kecualikan alamat gateway dengan excluded-address. IP 169.254.x.x = DHCP tidak terjangkau.
    • VLSM: urutkan dari kebutuhan terbesar; link antar-router cukup /30.
    • Static route harus ada di kedua arah. Kalau R2 tidak tahu jalan pulang, ping berakhir Request timed out.
