VLSM & Static Route

Bagi alamat sesuai kebutuhan tiap segmen, lalu ajari kedua router jalan menuju jaringan di seberang.

Bagian A: VLSM

VLSM = subnet dengan ukuran berbeda sesuai kebutuhan. Rumus host valid: 2n − 2 (n = jumlah bit host) (dikurangi network address dan broadcast address).

Trik: hitung kebutuhan + 2, lalu cari ukuran blok terkecil (4, 8, 16, 32, 64, 128, 256) yang muat.

PrefixMaskBlokHost

Tugas:
  • Latihan 1: hitung subnet link R1–R2 (2 host) dari 192.168.100.0.
  • Latihan 2: pilih prefix yang tepat untuk 5 segmen dari 192.168.50.0/24.

Latihan 1 · Link R1–R2 (mulai dari 192.168.100.0)

Kabel antara R1 dan R2 hanya dipakai 2 perangkat: R1 dan R2. Jadi kebutuhan host di soal ini sudah pasti 2. Hitung semua kotak di bawah untuk kebutuhan 2 host ini.

Coba sendiri dengan jumlah host lain (tidak dinilai)
Ketik jumlah host untuk melihat perhitungannya.

Latihan 2 · Bagi 192.168.50.0/24 untuk 5 segmen

Segmen sudah diurutkan dari kebutuhan terbesar. Pilih prefix paling hemat yang masih muat, lalu tekan Hitung alokasi.

Bagian B: Static route

Router hanya otomatis mengenal jaringan yang terhubung langsung (kode C). Untuk jaringan di balik router lain, kita menulis static route. Mirip petugas pos yang diberi tahu: “Surat untuk kota B, titipkan ke kantor pos sebelah.”

ip route <network-tujuan> <subnet-mask> <next-hop>

Tugas (dicentang otomatis):
  • R1 punya rute ke 192.168.30.0/24
  • R1 punya rute ke 192.168.40.0/24
  • R2 punya rute kembali ke VLAN 10 dan 20 (paling praktis: default route 0.0.0.0/0 ke R1)
  • Ping PC1 → PC3 berhasil
  • Ping PC3 → PC1 berhasil
C:\> (pilih PC lalu tekan Kirim ping)
