Router-on-a-Stick & DHCP

Switch tidak bisa menyeberangkan data antar-VLAN. Router yang melakukannya, cukup lewat satu kabel trunk.

Bagian A: Subinterface R1

Port fisik Gi0/0 dibagi menjadi subinterface: Gi0/0.10 untuk VLAN 10 dan Gi0/0.20 untuk VLAN 20. IP subinterface menjadi default gateway PC di VLAN itu.

Tugas:
  • Lengkapi konfigurasi R1 sampai semua subinterface up, lalu tekan Periksa R1.
R1(config)# interface g0/0
no ip address Gi0/0: mati
interface g0/0.10 (VLAN 10)
Gi0/0.10: mati
interface g0/0.20 (VLAN 20)
Gi0/0.20: mati

Konfigurasi R1


      

      

        
R1# show ip interface brief

        

      

    


    

      
    

    
  • Pilih nilai untuk tiap subinterface, nyalakan no shutdown, lalu tekan Periksa R1.


    
Perjalanan ping PC1 (VLAN 10) → PC2 (VLAN 20)

    

    
    
      
  1. PC1 melihat tujuan 192.168.20.6 ada di subnet lain, jadi paket dikirim ke gateway 192.168.10.1.
    2. 
      
  2. SW1 menerima di port access VLAN 10, menambah tag 10, lalu mengirim lewat trunk Fa0/1.
    3. 
      
  3. R1 menerima di Gi0/0.10, cek tabel routing: 192.168.20.0 ada di Gi0/0.20.
    4. 
      
  4. R1 mengirim keluar Gi0/0.20 dengan tag 20, lewat kabel trunk yang sama.
    5. 
      
  5. SW1 melepas tag dan meneruskan ke Fa0/3 (VLAN 20). PC2 menerima.

Bagian B: DHCP di R1 untuk VLAN 20

    

      
DHCP membagikan IP, subnet mask, gateway, dan DNS secara otomatis. Mirip petugas pendaftaran yang membagikan nomor antrean: tidak ada dua tamu yang memegang nomor sama.

    

    

      Tugas:
      
    
        
  • Susun 4 pesan DHCP (DORA) dengan urutan yang benar.
    • 
        
  • Isi pool DHCP sampai PC2 mendapat 192.168.20.6 dengan gateway dan DNS yang benar.
    • 
      

    


    
1. Susun urutan DORA

    
Ketuk kartu di bawah sesuai urutan kejadian. Ketuk kotak yang sudah terisi untuk mengembalikannya.
